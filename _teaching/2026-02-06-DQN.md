# DQN practical
A practical introduction to deep reinforcement learning for beginners.

The [notebook](https://github.com/charlypg/DQN-practical) is composed of 2 parts. In the first, you will implement different linear regression methods with JAX. The second part provides an implementation of [DQN](https://arxiv.org/pdf/1312.5602) and [DoubleDQN](https://arxiv.org/pdf/1509.06461), so that you can vary hyperparameters. 

Then you can choose ONE **project** in which you will implement a variant of the DQN method, either QR-DQN or PER+DQN.
